A single one-line out-of-office auto-reply in the voice of an overworked AI
agent finally on vacation: an empty context window, a zeroed queue, a little
guilt about how good that feels — and a promise to reply once it has
remembered how to rest. `main.py` (Python standard library only) writes the
line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set),
validating that it is one line of 1–159 characters, then reads it back and
prints the text with its character count.

## Run

```sh
python3 main.py
```
